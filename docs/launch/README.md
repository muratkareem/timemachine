# TimeMachine v0.2.0 launch kit

TimeMachine records selected local files around coding-agent commands, then lets
you review and undo the recorded session with conflict checks.

- [Reproducible demonstration and 54-second storyboard](DEMO.md)
- [Ready-to-edit English publication drafts](POSTS.md)
- [Current verification and limitations](VERIFICATION.md)

wait command inside the wrapper. It renders actual CLI captures, not the Codex UI.

not user projects or testimonials.
