# TimeMachine v0.1.0

Undo AI coding agent changes without losing your own work.

This first release supports Python 3.12–3.14 on macOS and Linux local
filesystems. The wheel, source archive, checksums and build manifest are attached.
The GitHub release is published; PyPI publication remains pending verified package
ownership and upload credentials.

- SHA-256 deduplicated PRE/POST snapshots and inherited-terminal command wrapping.
- Conflict-safe undo/redo and file/directory selective checkpoint recovery.
- Exact reviewed intent, Git/context and path-identity revalidation before writes.
- Recovery checkpoints, integrity-checked chained journals and explicit interrupted recovery.
- Strict catalog/foreign-key validation before garbage collection.
- Optional Textual workspace with paged history, searchable diffs, line numbers,
  binary/large-file summaries, metadata/type changes and dark/light themes.
- Human/JSON CLI, quickstart, agent discovery, version reporting and optional
  reviewable Bash/Zsh functions for natural Codex/Claude/Gemini/Aider launches.
- Reproducible wheel/sdist builds and no-clone commit-archive installation.
- Measured disposable workloads through 50,000 files and 1,000 saved checkpoints.

Existing catalog v1 stores remain readable. Writes require an explicit
`timemachine migrate --preview`, then `timemachine migrate --yes`. Migration backs
up the catalog and preserves v1 manifests/objects/journals. The catalog backup is
not an independent whole-store backup; keep the complete store independently.

Stop external writers before recovery. Multi-file restore is not globally atomic.
Ignored files are included unless explicitly excluded and can contain secrets.
Git history/index, external files, ownership, timestamps, ACLs/xattrs, hardlinks and
special files are outside the recovery contract. The wrapper is not a sandbox.

Native Windows, hunk-level recovery, automatic vendor hooks, watch mode, export,
compression and background services are deferred. Hunk recovery needs reviewed
content/context matching and concurrent-edit conflict detection before it can
extend the current exact file-level contract. No blind patch implementation ships.

See the repository's installation, safety, recovery, benchmarks and production
delivery reports for precise validation and publication status.

Install without cloning (with uv and Python 3.12+):

```sh
uv tool install --python 3.12 "https://github.com/muratkareem/timemachine/releases/download/v0.1.0/timemachine_cli-0.1.0-py3-none-any.whl[tui]"
```

Run `timemachine quickstart` to get started. Initialization alone creates no backup;
wrap agent sessions with `timemachine run -- COMMAND`.
