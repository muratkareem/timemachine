TimeMachine v0.2.0 makes local recovery easier to understand while preserving its conflict checks and recovery journals.

## Highlights
- Simple mode opens with saved-state status, changed files, a readable diff and contextual Undo/Redo.
- Advanced mode preserves history, comparisons, storage details and selective recovery.
- Original pixel styling, dark/light themes, keyboard and mouse controls, and responsive layouts from 60×24 to 207×58.
- Cancel-first recovery reviews show exact paths and revalidate current files before applying changes.
- Beginner Help and a runnable quickstart support any executable; no particular agent is required.

## Install
Requires Python 3.12+ on macOS or Linux:

```sh
uv tool install --python 3.12 'https://github.com/muratkareem/timemachine/releases/download/v0.2.0/timemachine_cli-0.2.0-py3-none-any.whl[tui]'
```

Run `timemachine quickstart`, initialize your project, then wrap a command with `timemachine run -- COMMAND`. Initialization alone does not save files.

## Scope and limitations
Recovery preserves unrelated edits and refuses conflicting changes. Pause external writers; recovery is not globally atomic. Git history/index and excluded files are outside recovery scope. Native Windows, hunk recovery and automatic vendor hooks remain unsupported. Previews and recovery reviews are bounded; large reviews use the CLI. No authenticated agent or external human usability study is claimed. No PyPI upload was performed.
