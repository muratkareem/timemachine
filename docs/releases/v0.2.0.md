# v0.2.0 — Simple by default, advanced when needed

Prepared for owner review; no merge, tag or publication has occurred.

Simple mode reduces the workspace to status, changed files and a reviewed recovery
action. Advanced mode retains the pixel workspace, full history, metadata and
selective recovery. Help and the beginner quickstart work with any command.

Compatible with v0.1.0 manifest v1/catalog v2. No new migration or CLI JSON change.
macOS/Linux, Python 3.12+; native Windows remains unsupported. Existing conflict,
frozen-plan, recovery journal and Git safeguards are retained.

See [the final product report](../PRODUCT_DELIVERY.md), [installation](../INSTALL.md)
and [safety contract](../SAFETY.md). Owner approval is required before merge/release.
