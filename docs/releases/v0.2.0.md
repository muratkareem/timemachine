# TimeMachine v0.2.0 · release candidate

**Prepared for review; not tagged or published.** Existing v0.1.0 assets and tag
are preserved. Python 3.12+ on macOS/Linux local filesystems; native Windows remains
unsupported. Publication requires a new explicit maintainer approval.

- Original pixel hourglass, save-state slots, square frames and matching dark/light
  semantics and source/diff syntax colors.
- Broader mission-log archive and inventory, separate diff stage and factual ledger.
- Contextual Undo/Redo based on backend eligibility, with session/snapshot identity
  in the exact frozen review. Cancel remains the default.
- File/directory recovery from the inventory, Unicode path filters and 200-row pages.
- Stable history cursors, eight-manifest cache, cancellable read workers and no-I/O
  theme repaint that preserves selection. No animation or background service.
- Responsive 1/2/3 pane navigation at 60x24 through 200x55, accessible contrast,
  ASCII/no-color modes, keyboard field guide and clear initialization/backup wording.
- Reproducible actual-state screenshot gallery, published-wheel functional comparison,
  bounded preview and process/safety/CLI regression verification.

Compatibility: manifest v1 and catalog v2 remain unchanged; upgrading from v0.1.0
requires no new migration. Older catalog v1 still uses the existing explicit migrate
command. Console JSON contracts remain; package --version now reports 0.2.0.
The only core refactor shares the identical eligible-run query with UI readers;
restore, snapshot, storage and Git engines are preserved.

UI limits: preview 1 MiB/file, 2,000 display lines, 500 characters/line; find searches
the displayed portion. Recovery reviews over 500 entries disable Apply and direct
the user to CLI --preview. File inventory has Previous/Next pages, not hunk restore.

Unchanged safety scope: stop external writers. Multi-file restoration is not globally
atomic; same-user malicious processes can access the store. Git history/index,
external targets, ACLs/xattrs, ownership and timestamps are not restored. Ignored
files may contain secrets. No unsafe force path or blind patching is introduced.
Authenticated/billable vendor sessions, native Windows, vendor-hook adapters,
hunk recovery, watch, export and compression are not added by this release.

See PIXEL_DELIVERY.md for actual test counts, CI, measurements, screenshots, scores
and release checklist before approval. PyPI remains blocked by ownership/credentials.
